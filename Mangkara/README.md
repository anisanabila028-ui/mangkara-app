# Mangkara

## Deskripsi
Mangkara ( Manggihan ) adalah aplikasi yang membantu siswa mencari informasi tempat Praktik Kerja Lapangan (PKL) dan mengajukan PKL secara lebih mudah.

## Tujuan
Memudahkan siswa mendapatkan informasi perusahaan, melihat detail tempat PKL, dan melakukan pengajuan PKL.

## Teknologi
- Next.js
- TypeScript
- Tailwind CSS
- Strapi untuk backend (direncanakan atau digunakan sesuai progres proyek)

## Fitur Utama
- Login
- Dashboard
- Daftar tempat PKL
- Detail tempat PKL
- Pengajuan PKL
- Halaman pengajuan berhasil
- Ulasan

## Menjalankan Proyek
1. Instal dependency dengan `npm install`.
2. Jalankan aplikasi dengan `npm run dev`.
3. Buka `http://localhost:3000` di browser.

## Pengembang
Proyek aplikasi Mangkara untuk mendukung kebutuhan informasi dan pengajuan PKL siswa.
